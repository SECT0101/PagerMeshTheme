# Changelog

MESH.5 theme versions for the WiFi Pineapple Pager. Newest first.

## 1.0.0
- First public release: MESH.5, a LoRa mesh theme in Meshtastic green for the Hak5 WiFi Pineapple Pager, made to go with the PagerMesh payload, with the MESH.5 LoRa Mesh Edition shield and Tac-Pine as a mesh operator.
- **MESH THE PLANET!** boot finale.
- **Eight matching ringtones** (`.rtttl`) for the Pager's ringtone slots.
- Downloads on the release: the theme, the ringtones and the art.
- Developed and tested on Pager firmware 2.0.0-stable.
